方法一：在线构建 APK（推荐）

使用在线服务一键生成 APK，无需安装任何软件

1
访问在线构建服务
2
上传我们的 Web 应用
3
下载 APK 安装包
打开 Appilane 在线构建 或者使用 NativeHTML

方法二：使用 Android Studio

需要安装 Node.js、JDK 和 Android Studio

1
安装 Node.js
2
安装 JDK 17+
3
安装 Android Studio
4
运行 build_apk.bat

方法三：使用 Capacitor Cloud Build

使用 Ionic 的在线构建服务

1
访问 Capacitor Cloud Build
2
上传项目或连接 GitHub
3
在线构建 APK
前往 Cloud Build

使用方法

构建完成后，安装 APK 到手机：

1
确保手机和电脑在同一 WiFi
2
电脑上运行 mobile/server.py
3
打开手机 App，配置 WebSocket 地址

获取电脑 IP

在电脑上运行：

ipconfig

找到 IPv4 地址，例如 192.168.1.100
