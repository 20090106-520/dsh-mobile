# DSH Mobile - 内网穿透配置指南

让手机在任何网络下都能连接电脑端 DSH。

## 方案一：Cloudflare Tunnel（推荐，完全免费）

### 优点
- 完全免费
- 不需要注册域名
- 速度较快
- 支持 HTTPS/WSS

### 步骤

#### 1. 安装 cloudflared

**Windows:**
```bash
# 使用 Chocolatey
choco install cloudflared

# 或手动下载
https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
```

**Mac:**
```bash
brew install cloudflared
```

**Linux:**
```bash
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cloudflared.deb
sudo dpkg -i cloudflared.deb
```

#### 2. 登录 Cloudflare

```bash
cloudflared tunnel login
```

浏览器会打开登录页面，按提示操作。

#### 3. 创建隧道

```bash
cloudflared tunnel create dsh-mobile
```

记住输出的 Tunnel ID。

#### 4. 配置隧道

创建配置文件 `~/.cloudflared/config.yml`:
```yaml
tunnel: YOUR_TUNNEL_ID
credentials-file: C:\Users\你的用户名\.cloudflared\TUNNEL_ID.json

ingress:
  - hostname: dsh-mobile.your-domain.com
    service: http://localhost:3081
  - service: http_status:404
```

#### 5. 启动隧道

```bash
cloudflared tunnel run dsh-mobile
```

#### 6. 获取公网地址

启动后，你会看到类似:
```
https://abc123.ngrok-free.app
```

或者访问 https://dash.cloudflare.com/one/tunnels 查看。

#### 7. 配置手机

在手机 App 中填写:
- WebSocket 地址: `wss://你的隧道地址/ws`
- HTTP 地址: `https://你的隧道地址`

## 方案二：ngrok（免费，有带宽限制）

### 优点
- 简单易用
- 有免费版

### 缺点
- 免费版有带宽限制
- 地址每次重启会变化

### 步骤

#### 1. 安装 ngrok

**Windows:**
```bash
# 使用 Scoop
scoop install ngrok

# 或手动下载
https://ngrok.com/download
```

#### 2. 注册账号

访问 https://dashboard.ngrok.com/signup

#### 3. 登录

```bash
ngrok config add-authtoken YOUR_TOKEN
```

#### 4. 启动隧道

```bash
ngrok http 3081
```

#### 5. 获取公网地址

启动后会显示:
```
Forwarding  https://abc123.ngrok-free.app -> http://localhost:3081
```

#### 6. 配置手机

在手机 App 中填写:
- WebSocket 地址: `wss://abc123.ngrok-free.app`
- HTTP 地址: `https://abc123.ngrok-free.app`

## 方案三：本地网络（同一 WiFi）

如果手机和电脑在同一 WiFi 下:

### 1. 启动服务器

```bash
cd mobile
python server.py
```

### 2. 获取电脑 IP

```bash
ipconfig
```

找到 `IPv4 地址`，例如 `192.168.1.100`

### 3. 手机连接

在手机 App 中填写:
- WebSocket 地址: `ws://192.168.1.100:3081`

## 端口说明

| 端口 | 协议 | 用途 |
|------|------|------|
| 3081 | HTTP + WebSocket | 手机连接 |

确保防火墙允许此端口。

---

## 常见问题

### Q: 为什么连接失败？
A: 检查防火墙设置，确保 3081 端口开放。

### Q: 手机和电脑不在同一网络怎么办？
A: 使用 Cloudflare Tunnel 或 ngrok 创建公网地址。

### Q: 隧道地址会变吗？
A: Cloudflare Tunnel 地址固定；ngrok 免费版每次重启会变。
